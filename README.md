## exporter: Conversor Markdown → PDF

Simple like that.

### Instalação

```bash
pip install -r requirements.txt
```

### Uso CLI

```bash
python render.py arquivo-entrada.md arquivo-saida.pdf
```

- Uses the default PDF layout provided by the library.
- The font used in the PDF is **Poppins** (Google Fonts).
- No theme customization is applied except for the font.
